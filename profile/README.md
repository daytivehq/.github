# Daytive

**English** · [한국어](#한국어)

Tools for everyday life.  
We build simple, self-hosted apps and utilities to make daily routines a little lighter.

- **Website**: [daytive.com](https://daytive.com)
- **Contact**: contact@daytive.com

## Apps

| App | Description | Links |
| :--- | :--- | :--- |
| **[Duet Ledger](https://github.com/daytivehq/duet-ledger)** | Self-hosted personal & shared household ledger. | [Install Guide](https://github.com/daytivehq/duet-ledger/blob/main/manual/ko/installation.md) |
| **[Receipt Bridge](https://github.com/daytivehq/receipt-bridge)** | Analyze receipt photos & expense text with AI and save to Duet Ledger. | [Docker Setup](https://github.com/daytivehq/receipt-bridge#docker로-설치) |
| **[linktive](https://github.com/daytivehq/linktive)** | Lightweight, fast self-hosted bookmark & web archiving service. | [Details](https://daytive.com/linktive/) · [Chrome Extension](https://chromewebstore.google.com/detail/linktive/opalenmkjhflejpemlkbliiadchgjhje) |

All apps are designed to be self-hosted on your own server via Docker.
